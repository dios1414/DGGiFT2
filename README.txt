# DG GIFT — nueva versión

## Archivos
- `index.html`: creador de regalos.
- `styles.css`: diseño adaptable a celulares.
- `app.js`: vista previa, creación del regalo HTML y QR.

## Cómo publicar el creador
Subí estos tres archivos a tu repositorio de GitHub, reemplazando los anteriores. Luego conectá/actualizá el proyecto en Cloudflare Pages o el servicio que estés usando.

## Cómo crear un regalo
1. Abrí la página del creador.
2. Completá dedicatoria, fotos (hasta 20), enlace de YouTube y video MP4.
3. Tocá “Crear y descargar mi regalo”.
4. Se descarga `mi-regalo-dg-gift.html`.
5. Publicá ese HTML en Cloudflare Pages para obtener un enlace público.
6. Pegá ese enlace en “Enlace público del regalo” y generá/descargá el QR.

## Importante
- La música de YouTube se muestra como reproductor incrustado. La persona puede tener que tocar reproducir; los navegadores suelen bloquear el autoplay.
- El video y las fotos quedan incluidos dentro del HTML descargado. Para que el archivo sea fácil de compartir, conviene usar fotos optimizadas y un MP4 corto/comprimido.
- El QR necesita el enlace público final. No sirve generarlo antes de publicar el regalo.
- El reproductor de YouTube necesita conexión a internet.
